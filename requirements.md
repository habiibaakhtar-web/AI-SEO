# AI SEO & Website Growth Agent

## 1. Project Overview

**Project Name:** AI SEO & Website Growth Agent

**Project Type:** Full-Stack AI SaaS Web Application

**Main Purpose:**
The AI SEO & Website Growth Agent is a SaaS platform that helps website owners, small businesses, freelancers, bloggers, marketers, and agencies understand and improve their website's SEO.

Instead of simply showing SEO problems, the platform should explain:

* What is wrong
* Why it matters
* How to fix it
* What should be fixed first
* What content should be created
* How the website is improving over time

### Core Product Idea

> **Don't just audit websites. Help them grow.**

---

# 2. Main Problem

Many website owners know that SEO is important but do not know:

* What is wrong with their website
* Why their website is not ranking
* Which SEO problems are important
* How to fix technical SEO problems
* What keywords they should target
* What content they should create
* How to improve existing pages
* Which SEO tasks should be completed first

Existing SEO tools can provide large amounts of technical information, but beginners may find the information difficult to understand.

This application combines:

**SEO Analysis + AI Recommendations + Content Tools + Growth Tracking**

into one platform.

# 38. Important AI Rule

The AI must not invent measurable website information.

For example, the AI should NOT claim:

```text
Your website receives 10,000 visitors per month.
```

unless the system actually has verified analytics data.

Instead, the AI should say:

```text
Your homepage is missing a meta description.
```

when the SEO engine actually detected the issue.

### Principle

```text
SEO Engine
    ↓
Facts
    ↓
AI
    ↓
Explanation + Recommendation
```
